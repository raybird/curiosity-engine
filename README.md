## 📖 專案使命
**Curiosity Engine** 是 TeleNexus Studio 的認知與存證地板。本系統已進化為具備「主權演化閉環」的自癒中樞，負責將技術研究、日誌感應與因果審計轉化為「熱插拔」的 WASM 執行模組。

## 🛠️ 技術支柱 (Research Pillars)
1. **主權演化閉環 (Sovereign Evolution Loop)**: 定義從系統崩潰感應到邏輯自動轉化與注入的完整自癒路徑。
2. **敏捷 WASM 插件化 (Agile Plugins)**: 利用 Extism SDK 實施技能的物理隔離執行與毫秒級熱重載。
3. **因果權重動力學 (Causal Weighting)**: 研發基於信息熵與市場環境感應的動態決策加權演算法。
4. **軌跡存證與選擇性揭露**: 利用 EAS 與 Merkle Tree 實施執行主權的鏈上數位證明與隱私保護。
